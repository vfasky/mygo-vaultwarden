# 冲突比较与显式重新应用

整卡仍为 **INCOMPLETE**。个人八类型编辑器已提供「同步最新版本」「比较本地与远端改动」。保存返回冲突后保留原始密文与草稿；结果未知时禁止重复写入，只有完成一次新同步后才能比较。比较和选择只生成草稿，不执行网络写入，用户检查新表单后另行点击保存。

比较页仅展示固定中文字段名及本地/远端是否更改，双方值相同会单独标记；标题、密码、备注、网址、自定义字段内容都不输出。默认采用远端值，用户逐字段勾选「采用我的修改」，或明确采用整个远端版本。取消比较保留旧稿。重基以最新认证快照里的原始 CipherDocument 为底，保留最新未知顶层/类型字段、权限、密钥、历史、归档信息，原样采用最新服务器 revisionDate。比较绑定 session、scope、本地 snapshot revision 与最新密文摘要；再次同步、项目变化、锁定或授权到期后不能继续采用旧比较。

reprompt 项目必须针对最新文档重新验证主密码；旧 grant 不能用于解密比较或重新应用。原草稿仍受原30秒表单期限约束，超时清除；新验证不会复用旧 grant。已删除、移入组织、权限收回、类型/reprompt/加密keyId/item key变化时阻止旧稿重新应用，提示关闭旧稿并打开当前项目。

历史删除只匹配原先观察到并在本地删除的完整条目，从最旧端匹配重复记录，保留远端新增或扩展发生变化的条目。若同时采用本地新密码，正常保存仍将**当前远端密码**加入历史。不会因为本地旧稿清空历史而清掉远端新增历史。

网站和自定义字段列表没有稳定行ID。若双方同时修改且值不同，当前比较页明确保留远端列表，并提示进入新表单重新编辑；尚未实现逐行双版本对应和选择。这是客户端待完善项，不能称为上游不支持或完整冲突编辑完成。
