# 多语言（i18n）

应用支持简体中文和英文，默认跟随系统语言。启动时读取系统首选语言列表（`CFLocaleCopyPreferredLanguages`，包含“系统设置 > 通用 > 语言与地区 > 应用”中为本应用单独选择的语言），取第一个中文或英文；两者都不在列表中时使用英文。语言在启动时确定，切换后需重启应用。

- 强制指定：`MYGO_VAULTWARDEN_LANG=en` 或 `zh`。
- Go 测试默认使用中文；需要英文时在测试中调用 `i18n.Set(i18n.English)` 并在结束时恢复（`defer i18n.Set(i18n.Current())`）。

## Go 写法

界面文案用语义 key 查找，代码里不出现中文：

```go
ui.Text(c, i18n.T("common.save"))
a.status = i18n.Tf("app.sync.done", n)
return fmt.Errorf(i18n.T("backup.read_failed"), err)   // 文案为 "读取备份失败：%w"
var errLocked = errors.New(i18n.T("error.vault_locked"))
```

每条 key 在 `internal/i18n/<领域>.go` 中同时写出中文和英文：

```go
package i18n

func init() { register("vault.folder", vaultFolder) }

var vaultFolder = map[string]text{
	"vault.folder.title":          {"文件夹", "Folder"},
	"vault.folder.delete_confirm": {"删除文件夹“%s”？其中的项目会移到“无文件夹”。", "Delete folder “%s”? Its items move to No folder."},
}
```

### key 命名

- 全小写，`.` 分层，单词用 `_` 连接：`<领域>.<功能>.<名称>`，例如 `app.sidebar.items`、`vault.editor.add_website`、`org.member.invite`。
- 按含义命名，不按中文直译、不带序号；同一句话在两个地方含义相同才复用同一个 key。同一个中文词在不同位置含义不同（例如侧栏标题“项目”是 Items，导入结果里的“项目”是单个 Item），就用两个 key。
- 名称部分描述用途：按钮用动词（`save`、`delete_permanently`），标题用 `title`，说明用 `hint`/`description`，状态用 `status_*`，错误用 `err_*` 或放在 `error.*`。
- `register(area, …)` 的每个 key 必须以 `area.` 开头；同一个 key 只能定义一次。

### 规则

- 传给 `T`/`Tf` 的必须是 key 字面量；需要按状态选文案时，写一个返回 key 的 `switch` 或映射表（表里的 key 字面量算作已使用）。
- 不要拼接文案。带参数用 `Tf`；两种语言参数顺序不同时用 `%[1]s`、`%[2]d`。
- 程序状态（参与比较、持久化、发送到服务器、作为 map key）用稳定的 ASCII 标识或常量，显示时再查 key，不要拿界面文案当状态。
- 确实不应翻译的中文字面量（例如解析服务器返回的中文、测试样例数据）在同一行加注释 `// i18n:ignore`。
- 英文没有复数变化时用中性写法：`"Items: %d"`、`"%d item(s)"`。
- 按钮、标题用 sentence case（首词大写，品牌和专有名词如 Send、AutoFill、Bitwarden、API、SSH 除外）。
- 通用词放在 `common.*`，八种条目类型名放在 `itemtype.*`（见 `internal/i18n/common.go`）。只有多个领域含义完全相同的词才放进 common。

`internal/i18n` 的测试检查：生产代码中没有中文字面量；`T`/`Tf` 的 key 都已定义；每条中英文都不为空、英文不含中文、占位符一致（按参数序号比较）；key 格式正确且没有重复；没有未使用的 key。

### 领域划分

| 领域前缀 | 内容 |
|---|---|
| `common`、`itemtype` | 通用词、条目类型名 |
| `app`、`login` | 主窗口外壳、侧栏、工具栏、列表与详情、设置；登录、解锁、两步登录页面与同步状态 |
| `vault` | 条目编辑器、字段、冲突比较、附件、文件夹、批量操作、共享恢复 |
| `backup`、`crossaccount`、`send` | 备份导入导出与完整资源备份；跨账号目标恢复；Send |
| `account` | 账号设置、注册、改主密码、密钥轮换、API key、两步登录管理、设备与设备登录、紧急访问、账号恢复 |
| `org` | 组织：成员、策略、集合、群组、设置、共享（`org.member`、`org.policy` 等）与组织业务面板（`org.directory`、`org.events`、`org.ops`、`org.resource`、`org.transfer`、`org.apikey`） |
| `error`、`policy`、`server`、`store`、`file`、`sysauth` | 后台：哨兵错误、策略定义、协议校验与服务器结果、本机存储、文件暂存、系统认证 |

## Swift

Swift 端（AutoFill 扩展、存储桥消息、系统认证理由）用 `macos/Shared/SnapshotTypes.swift` 中的 `L10n`，语言选择规则与 Go 相同，同样按语义 key 查找中英文：`L10n.t("autofill.no_snapshot")`。
