# 多语言（i18n）

应用支持简体中文和英文，默认跟随系统语言。启动时读取系统首选语言列表（`CFLocaleCopyPreferredLanguages`，包含“系统设置 > 通用 > 语言与地区 > 应用”中为本应用单独选择的语言），取第一个中文或英文；两者都不在列表中时使用英文。语言在启动时确定，切换后需重启应用。

- 强制指定：`MYGO_VAULTWARDEN_LANG=en` 或 `zh`。
- Go 测试默认使用中文，现有断言中文文案的测试不受影响；需要英文时在测试中调用 `i18n.Set(i18n.English)` 并在结束时恢复。

## Go 写法

源文案用简体中文书写，同时作为词典 key：

```go
ui.Text(c, i18n.T("保存"))
a.status = i18n.Tf("已同步 %d 个项目", n)
return fmt.Errorf(i18n.T("读取备份失败：%w"), err)
var errLocked = errors.New(i18n.T("密码库已锁定。"))
```

- 传给 `T`/`Tf` 的必须是完整的字符串字面量。不要拼接（`"共享到 "+name`），改用 `Tf("共享到 %s", name)`，英文可调整词序（`%[1]s`）。
- 先赋值再显示的文案也要在字面量处包装：`label := i18n.T("保存")`。
- 同时作为程序状态的中文（参与比较、持久化、发送到服务器或作为 map key）保持中文值，用 `i18n.Key("已核验")` 标记，只在显示处 `i18n.T(row.State)`。
- 确实不应翻译的中文字面量（例如解析服务器返回的中文、测试样例数据）在同一行加注释 `// i18n:ignore`。
- 英文没有复数变化时用中性写法：`"Items: %d"`、`"%d item(s)"`。

英文词典在 `internal/i18n/en_<领域>.go`：

```go
package i18n

func init() { register("account", enAccount) }

var enAccount = map[string]string{
	"保存": "Save",
}
```

`internal/i18n` 的测试会检查：生产代码中没有未包装的中文字面量；每条源文案都有英文；译文不含中文；格式占位符（`%d`、`%s`、`%w`……）的种类和顺序一致；同一源文案在不同词典中的译文一致；词典没有未使用的条目。

## Swift

Swift 端（AutoFill 扩展、存储桥消息、系统认证理由）用 `macos/Shared` 中的 `L10n` 按同样规则选择语言并翻译。
