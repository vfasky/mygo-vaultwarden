经得起检验的安全设计Security designed to be verified

完整源码以 GPL-3.0 开放，任何人都可以检查与验证。 The full source is open under GPL-3.0 so anyone can inspect and verify it.

  • App 沙盒App Sandbox主应用与自动填充扩展均启用沙盒，文件访问仅限你明确选择的文件和目录。The app and its AutoFill extension both run sandboxed. File access is limited to what you explicitly choose.
  • 静态加密Encrypted at rest密码库以受 Keychain 与主密码保护的 AES-GCM 本机快照保存。The vault is stored as an AES-GCM snapshot protected by Keychain and your master password.
  • 最小权限自动填充Least-privilege AutoFill扩展在独立沙盒进程中运行，只读取过滤后的登录信息，须你选择并通过系统认证。The extension runs in a separate sandboxed process, reads only filtered login data, and needs your choice plus system authentication.
  • 强密钥派生Strong key derivation弱 KDF 参数会在发起任何在线请求前被拒绝。Weak KDF parameters are rejected before any network request is made.
  • 更新验签Verified updates安装更新前校验 Ed25519 签名与归档 SHA-256 摘要。Updates are checked against an Ed25519 signature and the archive SHA-256 digest before installing.
